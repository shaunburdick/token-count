# Homebrew Tap Setup Guide

This guide walks through setting up the Homebrew tap for token-count, including the formula and auto-update configuration.

## Prerequisites

- GitHub account with permission to create repositories
- Access to token-count repository settings (for secrets)

## Step 1: Create Homebrew Tap Repository

1. Go to https://github.com/new
2. Create new repository:
   - **Name**: `homebrew-tap` (Homebrew automatically strips "homebrew-" prefix)
   - **Description**: "Homebrew formulae for shaunburdick's tools"
   - **Public**: Yes (required for Homebrew taps)
   - **Initialize with**: README, LICENSE (MIT)

3. Clone the repository:
```bash
git clone https://github.com/shaunburdick/homebrew-tap.git
cd homebrew-tap
```

## Step 2: Create Formula Directory

```bash
mkdir -p Formula
cd Formula
```

## Step 3: Create token-count Formula

Create `Formula/token-count.rb` with the following content:

```ruby
# typed: false
# frozen_string_literal: true

# This file is auto-generated by GitHub Actions
# Manual edits will be overwritten on next release

class TokenCount < Formula
  desc "Count tokens for OpenAI API requests"
  homepage "https://github.com/shaunburdick/token-count"
  url "https://github.com/shaunburdick/token-count/archive/refs/tags/v0.1.0.tar.gz"
  sha256 "PLACEHOLDER_WILL_BE_UPDATED_BY_GITHUB_ACTIONS"
  license "MIT"
  head "https://github.com/shaunburdick/token-count.git", branch: "main"

  depends_on "rust" => :build

  def install
    system "cargo", "install", "--locked", "--root", prefix, "--path", "."
  end

  test do
    assert_match "token-count #{version}", shell_output("#{bin}/token-count --version")
    
    # Test basic functionality
    output = pipe_output("#{bin}/token-count", "Hello, world!")
    assert output.to_i > 0, "Expected token count > 0"
  end
end
```

**Important Notes**:
- The `url` and `sha256` will be automatically updated by GitHub Actions on each release
- The formula compiles from source using Cargo (most compatible approach)
- The `test` block ensures the binary works correctly

## Step 4: Commit and Push Formula

```bash
git add Formula/token-count.rb
git commit -m "Add token-count formula"
git push origin main
```

## Step 5: Set Up Personal Access Token

The GitHub Actions workflow needs permission to update the formula automatically.

1. **Generate Personal Access Token**:
   - Go to: https://github.com/settings/tokens/new
   - **Note**: "Homebrew Tap Auto-Update for token-count"
   - **Expiration**: No expiration (or 1 year with renewal reminder)
   - **Scopes** (select both):
     - ✅ `repo` (Full control of private repositories)
     - ✅ `workflow` (Update GitHub Action workflows)
   - Click "Generate token"
   - **Copy the token immediately** (shown only once)

2. **Add Token to token-count Repository**:
   - Go to: https://github.com/shaunburdick/token-count/settings/secrets/actions
   - Click "New repository secret"
   - **Name**: `HOMEBREW_TAP_TOKEN`
   - **Value**: Paste the token from step 1
   - Click "Add secret"

## Step 6: Verify Auto-Update Configuration

The token-count repository already has the auto-update job in `.github/workflows/release.yml`.

Verify it includes:

```yaml
update-homebrew:
  name: Update Homebrew Formula
  needs: release
  runs-on: ubuntu-22.04
  if: startsWith(github.ref, 'refs/tags/v') && !contains(github.ref, '-')
  steps:
    - name: Update Homebrew formula
      uses: mislav/bump-homebrew-formula-action@v3
      with:
        formula-name: token-count
        homebrew-tap: shaunburdick/homebrew-tap
        base-branch: main
        download-url: https://github.com/shaunburdick/token-count/archive/refs/tags/v${{ steps.version.outputs.version }}.tar.gz
      env:
        COMMITTER_TOKEN: ${{ secrets.HOMEBREW_TAP_TOKEN }}
```

## Step 7: Test the Tap Locally

Before creating an official release, test the tap installation:

```bash
# Tap the repository
brew tap shaunburdick/tap

# Install token-count (will build from main branch)
brew install --build-from-source token-count

# Verify installation
token-count --version

# Test functionality
echo "Hello, world!" | token-count

# Run Homebrew's test
brew test token-count

# Uninstall
brew uninstall token-count
brew untap shaunburdick/tap
```

## Step 8: Test Auto-Update (with test release)

Create a test release to verify the auto-update workflow:

```bash
cd /path/to/token-count

# Create test tag (contains '-' so won't publish to crates.io)
git tag v0.1.0-rc1
git push origin v0.1.0-rc1
```

Monitor:
1. GitHub Actions in token-count repository
2. Check if homebrew-tap repository gets an automatic commit
3. Verify the formula was updated:
   - Version number changed
   - URL changed
   - SHA256 hash updated

Clean up test release:
```bash
# Delete tag and GitHub release
git tag -d v0.1.0-rc1
git push origin :refs/tags/v0.1.0-rc1
gh release delete v0.1.0-rc1 --yes
```

## Troubleshooting

### Auto-update fails with "403 Forbidden"
- **Cause**: Invalid or expired `HOMEBREW_TAP_TOKEN`
- **Fix**: Generate new token with `repo` + `workflow` scopes

### Formula SHA256 mismatch
- **Cause**: The action updates the formula before the release is fully published
- **Fix**: This is rare, but if it happens, manually trigger the action again or update the formula manually

### Formula test fails
- **Cause**: Binary doesn't work on the test platform
- **Fix**: Debug with `brew install --verbose --debug token-count`

### Cannot find tap
- **Cause**: Repository not public or wrong name format
- **Fix**: Ensure repository is named `homebrew-tap` and is public

## Manual Formula Update (Fallback)

If auto-update fails, update manually:

1. Get SHA256 of new release:
```bash
VERSION=0.1.0
curl -sSfL "https://github.com/shaunburdick/token-count/archive/refs/tags/v${VERSION}.tar.gz" | \
  shasum -a 256
```

2. Update formula:
```ruby
url "https://github.com/shaunburdick/token-count/archive/refs/tags/v0.1.0.tar.gz"
sha256 "NEW_HASH_HERE"
```

3. Commit and push:
```bash
git add Formula/token-count.rb
git commit -m "Update token-count to 0.1.0"
git push origin main
```

## Alternative: Pre-built Binaries

If you want to distribute pre-built binaries instead of compiling from source:

```ruby
class TokenCount < Formula
  desc "Count tokens for OpenAI API requests"
  homepage "https://github.com/shaunburdick/token-count"
  license "MIT"

  on_macos do
    if Hardware::CPU.arm?
      url "https://github.com/shaunburdick/token-count/releases/download/v0.1.0/token-count-0.1.0-aarch64-apple-darwin.tar.gz"
      sha256 "HASH_HERE"
    elsif Hardware::CPU.intel?
      url "https://github.com/shaunburdick/token-count/releases/download/v0.1.0/token-count-0.1.0-x86_64-apple-darwin.tar.gz"
      sha256 "HASH_HERE"
    end
  end

  on_linux do
    url "https://github.com/shaunburdick/token-count/releases/download/v0.1.0/token-count-0.1.0-x86_64-unknown-linux-gnu.tar.gz"
    sha256 "HASH_HERE"
  end

  def install
    bin.install "token-count"
  end

  test do
    assert_match "token-count #{version}", shell_output("#{bin}/token-count --version")
  end
end
```

**Pros**: Faster installation (no compilation)  
**Cons**: Larger formula file, harder to auto-update
